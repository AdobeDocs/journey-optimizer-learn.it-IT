# Acquisire un profilo e creare un pubblico

In questo video, scopri come creare uno schema di profilo, acquisire i dati dei clienti da un file CSV e creare un pubblico utilizzando gli attributi di profilo in Adobe Experience Platform.

Scopri come definire campi chiave come nome, e-mail, stato di fedeltà e reddito annuale, caricare dati reali dei clienti e utilizzarli per creare un pubblico di clienti di alto valore.
